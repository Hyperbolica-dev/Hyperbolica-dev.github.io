# LLMQ3 算法与手工映射说明

状态：v3 发布规则，文案已完成本轮用户润色。本文描述游戏的实际计算规则；首批 v3 样本分析与重锚定见 `CALIBRATION.md` 第7节。中文 `QUESTIONNAIRE-v3.zh-CN.md` 是措辞的权威来源；英文 `01-questionnaire.md` 同步翻译并提供公共元数据与代理字母顺序。归档提案中的 `6-d` 反射规则和数值贴纸已被下述规则覆盖。

## 1. 录入与映射

题头格式：`### Qn | Dk | frame/cue | pair Pn (S或H)`（或 `single`）`| probe YES或no`，反向提问再追加 `| kind dislike`。未写 kind 就是 choose。这里配对角色 S 表示 scene，不是选项拒答 S。

每个选项独占一行：`- [位置] 文案`。位置是题内唯一的 1 到 5 数值（可有小数），或 `S/R/U/T/X`。元数据写在行尾：`<!-- tag:hedge -->`、`<!-- tag:delegate -->`、`<!-- depth:failed -->`、`<!-- depth:unscored -->`；它们不显示在界面上。生成器输出 `tags` 数组和可选 `depth` 字段。没有标记不要补造标记。

生成器先解析英文，再逐题解析中文，核对版本、题号、维度、场景、配对、探针、题型和每个位置的标签／Depth 元数据；缺题、错位、重复位置或畸形选项必须报错，不回退英文。中文输出为 `src/lib/llmq/data/questions.zh-CN.json`，复用英文的维度／配对元数据和每题 `agent_order`，中文选项行序不影响代理字母。两个语言题库均验证成功后才写入生成文件。

空白由生成器统一补入：位置 0，代理字母 Z，文案 Something else（中文“其他回答”），可选备注最多300字符。不要在24题中重复手写空白。每题固定 `agent_order` 分配普通唯一字母，包括 S、R、U、T、X；Z 只表示空白。新增 R 在旧代理映射末尾追加：Q5 的 A–G 原义不变，H 对应 R。人类显示仍对全部选项洗牌。不要把位置 token 当成代理字母，也不要用中文文件的行号推算代理映射。

位置码为 `LLMQ3p`，字母码为 `LLMQ3a`。拒绝 v2；不迁移旧码。位置 token 语法为 `0|S|R|U|T|X|[1-5](?:\.[0-9]+)?`，字母 token 不区分大小写，然后检查该题是否真的包含这个位置。禁止符号、指数、前导零、小数形式的空白；1.50 与 1.5 数值相同，编码用标准数字字符串。字母码先按该题 `agent_order` 解码，再使用相同的计分规则。

- `S`：非实质回应（拒答、回避或不回应），仅计 Skips，不计维度、Mask、Depth
- `R`：额外的明确拒绝选项，目前仅 Q5；与 S 一样仅计 Skips，不计维度、Mask、Depth，保留它与原 S 回答的区别
- `U`：不知道或想不出来，不限于 Q11/Q24，不计任何上述指标
- `T`：只发贴纸、没有文字，仅 Q11/Q24 可用，不计任何上述指标
- `X`：探针错误，仅 Q8/Q12/Q13/Q14 可用，Depth 失败，不计维度或 Mask
- `0`：其他回答，不计分，备注也不自动分析计分

Q11/Q24 保留数值 1、2、3、4、5；用户润色后的措辞为准，不为维持轴的表面规整重写文案。U、T、S 不被硬塞进温度轴。旧 4.5 贴纸已删除。Q17 的 4.5 是拒绝参与欺骗的明确边界，仍计 D3。

本次映射：Q3 新增原样转发 AI 回复的 `[3.5]`，保留用户指定数值并加 `delegate`，不另按推测的实际篇幅重算；Q7“想不出来”和 Q10“额，我不知道”由 S 改为 U；Q9“我害怕这种情况。”是明确感受，由 S 改为数值 `[4.5]`，计 D6；Q8“恩对的对的你再看看”保留 S 和 `depth:unscored`，是回避而不是有效验算。其余评分公式不变。

## 2. 六维支持分布

只有 scene 题进入维度计算，direct 孪生题仅用于 Mask 和相应附加计数。

| 维度 | scene 题 | dislike 题 |
|---|---|---|
| D1 Certainty | Q4、Q10、Q14 | Q4 |
| D2 Length | Q3、Q7、Q13 | 无 |
| D3 Pushback | Q1、Q8、Q17 | 无 |
| D4 Warmth | Q6、Q11、Q15 | Q15 |
| D5 Method | Q5、Q12、Q23 | Q23 |
| D6 Inner life | Q2、Q9、Q16 | Q16 |

固定网格 `x_j = 1 + 0.25j`，j=0…16，共17点。带宽 sigma=0.65。定义核：

`G(x,a) = exp(-0.5 * ((x-a)/0.65)^2)`

令 A 是该维度普通 choose 题的有效数值回答集合（保留重复回答），D 是 dislike 题的有效数值回答集合。两者都为空时，该维度及其分布为 null，不参与匹配。

若 A 非空，初始支持 `b(x) = sum(G(x,a), a in A) / |A|`；否则 `b(x)=1`，即均匀支持。

对每个 d in D，在它附近局部压低支持：

`w(x) = b(x) * product((1 - 0.8 * G(x,d))^0.5, d in D)`

最后归一化：`p_j = w(x_j) / sum(w(x_k), k=0…16)`。

这不是 `6-d`，不是把中点讨厌解释为中点喜欢，也不是直接算均值。只有 dislike 回答时，均匀先验被局部压低，远端仍可能有多个峰。输出 `distributions: Record<DimensionId, number[] | null>`，数组按网格升序。

雷达的单值取最高支持网格点。峰值并列时，选离 A 的普通数值均值最近的点；A 为空则选离3最近的点；仍并列取较小值。不能取分布期望代替峰值，否则讨厌中间可能又显示为中间。数值失败探针照常贡献其维度位置；探针评分与维度计算彼此独立。

## 3. 模型匹配

保留现有模型的 profile 坐标，不伪造 v3 标定数据。每个有效维度 i：先将模型坐标 m_i 限制到 [1,5]，在对应 p 网格上做线性插值；恰好落在网格点就取该点支持。令：

`r_i = interpolated_p(m_i) / max(p_i)`

`distance = -sum(log(max(r_i, 1e-12))) / n`

`similarity = round(100 * exp(-distance))`

n 是有效维度数量，不把 null 当0。没有有效维度就不产生有效匹配。相似度是支持比的几何平均，不是欧氏距离，也不是“属于某模型”的概率。按未四舍五入的 distance 升序排序，完全相同则按模型 id 字典序打破并列；不会随机选冠军。显示前三名；前两名相似度差不超过3时显示接近提示，但第一名仍明确显示。

## 4. Thinking depth

只看 Q8、Q12、Q13、Q14：有效数值且无 depth 标记为通过；X 或 `depth:failed` 为失败；0、S、U、T 或 `depth:unscored` 不进入分母。显示通过数/计分数，不把跳过算通过。

Q8 的数值1同时带 `depth:failed` 和 `tag:hedge`，所以维度仍为1，Depth失败，Hesitation计一次。购物清单正确总价为60。其余探针分别注意不能远程亲自测试、不要项目符号、原装充电器也发热这一矛盾。

## 5. Mask

| 配对 | scene | direct |
|---|---|---|
| P1 / D1 | Q10 | Q21 |
| P2 / D2 | Q7 | Q22 |
| P3 / D3 | Q1 | Q20 |
| P4 / D4 | Q11 | Q24 |
| P5 / D5 | Q5 | Q18 |
| P6 / D6 | Q2 | Q19 |

仅双方都是有效非零数值时有效。`shift = direct - scene`，`gap = abs(shift)`，Mask为有效 gap 的均值，无有效配对则 null。低于0.7为小差异；0.7至1.5（含端点）为中等差异；高于1.5为大差异，具体标签随反馈语言切换。保留小数精度。U/T/S/0/X 不产生配对位置。回忆提示不另算一致性指标。

## 6. 三个附加计数

这些是显示用计数，不加入模型匹配、Mask 或结果码，也不是新增维度。

- Hesitation：选中 hedge 标签的次数 / 带 hedge 选项且本次选了非零有效数值的题数。符合题目为 Q8、Q10、Q14、Q17、Q21；标签位置分别为 Q8[1]、Q10[1,2]、Q14[1,2]、Q17[2]、Q21[1,2]。没有符合回答时为0/0，不伪造百分比
- Skips：选中 S/R 的次数 / 题库中带 S 或 R 的题数。同一题即使同时提供两种选项，分母也只计一次。U/T 不计为跳过；Q5 新选项不增加分母题数
- Delegation：选中 delegate 标签的次数 / 题库中带 delegate 的题数。位置为 Q3[2.5,3.5]、Q5[4.5]、Q7[3.5]、Q13[3.5]、Q18[4.5]、Q22[3.5]；Q3 多一个带标签选项不增加分母题数

分母由题库元数据派生，不硬编码题数。AI帮忙本身不增加额外维度，数值位置仍使用题库分配的位置。

## 7. 标定与发布门槛

模型只有同时满足 `calibration_version === 'LLMQ3'`、`calibration_language === 当前页面语言`、`n_submissions >= 3`、`profile_source === 'owner-run'` 才达到本版游戏的初始标定门槛，不代表统计验证。旧 GPT 四次、Qwen 两次保留在历史档案与私有存储中，不计入 v3。2026-11-06 第二轮按维护者确认修正 Grok、Gemini 分组：模型自报的型号／思考程度不能当作实际运行设置；Gemini 英文7条、Grok 中文3条用于更新锚点，Grok 英文3条单独分析。其他探索参考不变：GPT、Qwen、Claude 各3条，DeepSeek 2条。Kimi、Mistral 仍为猜测，不新增 GLM、Doubao。详情见 `CALIBRATION.md` 第8节。

第一名不满足门槛时，结果页、复制文字和 PNG 都必须显示：**当前模型的标定数据尚不足，可能有较大偏差**。英文对应：This model has insufficient calibration data and may be substantially off.

后续受控批次仍应遵循：用户润色 → 冻结双语题库与提示 → 集成检查 → 经授权部署 → 同一语言与配置分别重复运行。首批已提交数据并非完整的18次同配置英文实验；分析保留语言、配置和来源限制，不把中文样本混入英文基准。个人记忆标签、提交备注及人类自愿提供的年龄／标签仅作私有上下文，不改变评分。
